## 📌 Project Overview
An end-to-end data analytics project focused on the financial and operational health of **Ninaidevi Shetimal Sahakari Sanstha** (An Agricultural Cooperative Society). The project transforms raw financial data into actionable insights to monitor profitability, loan repayments, and processing efficiency.

---

## 🚀 Key Features of the Dashboard
* **Profitability Tracking:** Multi-year analysis of PAT (Profit After Tax) and PBT trends.
* **Operational Metrics:** Visualizing Capacity Utilization (%) vs. Annual Paddy Processing (Tons).
* **Revenue Streams:** Dynamic breakdown of sales from Rice vs. By-products.
* **Debt Management:** A dedicated view for Loan Repayment Schedules and Debt Service Coverage Ratio (DSCR).
* **Human Capital Costing:** Department-wise salary distribution and staffing efficiency.

---

## 🛠️ Technical Stack & Workflow
### 1. Data Engineering (SQL)
Used SQL for data structuring and complex querying:
* Created relational tables for `Master Financials`, `Staffing`, and `Repayment Schedules`.
* Performed **Join operations** to link operational costs with annual profits.
* Wrote **Window Functions** to calculate cumulative loan repayments.

### 2. Data Visualization (Power BI)
* **DAX Measures:** Created custom measures for YoY growth and margin percentages.
* **Interactive Slicers:** Enabled filtering by Year and Department.
* **Data Modeling:** Established a Star Schema for optimized dashboard performance.
